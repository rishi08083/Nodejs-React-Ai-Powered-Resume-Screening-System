# ATS Node.js Backend

This project is a backend service for the ATS (Applicant Tracking System) built using Node.js.

## Installation

1. Clone the repository:
```sh
git clone https://github.com/vinaydanidhariya/ATS-Node-js-Backend.git
```
2. Navigate to the project directory:
```sh
cd ATS-Node-js-Backend
```
3. Install the dependencies:
```sh
npm install
```

## Usage

1. Start the server:
```sh
npm start
```
2. The server will be running at `http://localhost:3000`.
